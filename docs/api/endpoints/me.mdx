<div className="endpoint"><span className="method get">GET</span>/api/v1/me/</div>

Returns the key you sent. Use it to check your setup; it touches no player data.

<Tabs groupId="lang" queryString>
<TabItem value="curl" label="curl">

```bash
curl https://bonkverse.io/api/v1/me/ \
  -H "Authorization: Bearer $BONKVERSE_API_KEY"
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
const res = await fetch("https://bonkverse.io/api/v1/me/", {
  headers: { Authorization: `Bearer ${process.env.BONKVERSE_API_KEY}` },
});
const { ok, data, error } = await res.json();
console.log(ok ? `Key works: ${data.name}` : `Key problem: ${error}`);
```

</TabItem>
<TabItem value="python" label="Python">

```python
import os
import requests

res = requests.get(
    "https://bonkverse.io/api/v1/me/",
    headers={"Authorization": f"Bearer {os.environ['BONKVERSE_API_KEY']}"},
    timeout=10,
)
body = res.json()
print(f"Key works: {body['data']['name']}" if body["ok"] else f"Key problem: {body['error']}")
```

</TabItem>

## Response

```json
{
  "ok": true,
  "data": {
    "name": "Luna comp leaderboard",
    "prefix": "bvk_ab12cd34",
    "tier": "partner",
    "created_at": "2026-11-08T22:10:00+00:00"
  }
}
```

| Field | Type | |
|---|---|---|
| `name` | string | What the key is for |
| `prefix` | string | The shareable part of your key |
| `tier` | `"standard"` or `"partner"` | Decides your [rate limits](../rate-limits.md) |
| `created_at` | ISO 8601 time | |

**Errors:** `missing_api_key`, `invalid_api_key` ([all errors](../errors.md)).
